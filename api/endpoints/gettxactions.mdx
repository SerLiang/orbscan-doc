---
title: "Get actions by transaction hash"
description: "Decode a transaction into its Orbscan summary and actions."
api: "GET /open-api/v1/tx/{hash}"
---

Decodes one on-chain transaction into a human-readable summary and its underlying actions. The supplied test request returned HTTP `200` and 13 action records.

## Request

`GET https://orbscan.com/open-api/v1/tx/{hash}`

<ParamField path="hash" type="string" required>
  The 0x-prefixed transaction hash.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Orbscan Open API key.
</ParamField>

```bash
curl "https://orbscan.com/open-api/v1/tx/0x66dc87fb47faf587002b89d183dbb9505fc7ef80da5e6ec49e271278e8d95fad?apikey=$ORBSCAN_API_KEY"
```

## Transaction fields

| Field | Type | Description |
|---|---|---|
| `txHash` | string | Requested transaction hash. |
| `blockNumber` | integer | Block containing the transaction. |
| `blockTimestamp` | integer | Unix timestamp for the block. |
| `profileAddress` | string | Profile wallet identified as the primary actor. |
| `sourceType` | string | Orbscan transaction classification. |
| `actionType` | string | Primary action, such as `Buy` or `Sell`. |
| `sentence` | string | Human-readable transaction summary. |
| `marketSlug` | string | URL-safe market identifier. |
| `marketId` | string | Orbscan market identifier. |
| `actions` | array | Individual actions decoded from the transaction. |
| `comboActions` | array or null | Combo-market actions when present. |

## Action fields

Each object in `actions` can include `actionType`, `assetId`, `shares`, `price`, `txValue`, `actor`, `txHash`, `blockTimestamp`, `fee`, `marketId`, `marketSlug`, `eventSlug`, `marketTitle`, `positionSide`, `outcomeIndex`, `marketLogo`, and `liquidityRole`.
