---
title: "List deposits and withdrawals"
description: "Return a trader's deposit and withdrawal history."
api: "GET /open-api/v1/trader/{address}/deposits-withdrawals"
---

Returns deposits and withdrawals for a trader. The supplied test request returned HTTP `200`, 20 records, and an opaque `nextCursor` value.

## Request

`GET https://orbscan.com/open-api/v1/trader/{address}/deposits-withdrawals`

<ParamField path="address" type="string" required>
  The 0x-prefixed trader wallet address.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Orbscan Open API key.
</ParamField>

```bash
curl "https://orbscan.com/open-api/v1/trader/0x43372356634781eea88d61bbdd7824cdce958882/deposits-withdrawals?apikey=$ORBSCAN_API_KEY"
```

## Successful response

```json
{
  "success": true,
  "code": "0",
  "message": "success",
  "data": {
    "items": [
      {
        "txHash": "0x9c094e302971de8a6df70ee386bc3815597cbc24002b5f26e25c7127382efa31",
        "type": "deposit",
        "amount": 96240.383886,
        "time": 1786369038,
        "address": "0x0000000000000000000000000000000000000000"
      }
    ],
    "nextCursor": "opaque cursor"
  }
}
```

## Response fields

| Field | Type | Description |
|---|---|---|
| `data.items` | array | Deposit and withdrawal records. |
| `txHash` | string | On-chain transaction hash. |
| `type` | string | Either `deposit` or `withdrawal`. |
| `amount` | number | Transfer amount. |
| `time` | integer | Unix timestamp for the transfer. |
| `address` | string | Address associated with the transfer. |
| `data.nextCursor` | string or null | Cursor supplied when another page is available. |
