Use this endpoint to pull a wallet's buy, sell, and redeem activity across Polymarket markets, newest first.

Each item identifies the action (`actionType`), market (`marketTitle`, `marketSlug`), price and size (`price`, `size`), and number of shares moved (`netSharesTransferred`). Prices are decimals from 0 to 1, so `"0.78"` means 78 cents per share.

<Tip>
  Results are paginated. When the response includes a `nextCursor`, pass it back as the `cursor` query parameter to fetch the next page. When `nextCursor` is `null`, you've reached the end.
</Tip>

## Filtering

You can narrow results with any combination of:

- **`marketIds`**: Comma-separated market IDs, such as `?marketIds=2707644,2682268`.
- **`txHash`**: A single transaction hash. The API converts it to lowercase.
- **`fromBlock` / `toBlock`**: A block-height range.
- **`fromTimestamp` / `toTimestamp`**: A time range in Unix seconds.
