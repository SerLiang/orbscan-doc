title: "Get Actions by Transaction Hash"
sidebarTitle: "Get Actions by Hash"
description: "Decode a single transaction into a plain-English summary plus every individual on-chain fill it contains."
openapi: "openapi.json GET /v1/tx/{txHash}"
---

Use this endpoint to look **inside a single transaction**. Given a transaction hash, it returns a decoded summary and a breakdown of every on-chain action (fill) that happened within it.

The top-level `sentence` field gives you a ready-to-read description, for example:

> Buy 3604.58 No for $3546.12269 in Will Bitcoin dip to $59,000 on June 9?

The `actions` array then lists each individual fill — one transaction often contains several, because a single trade can be matched against multiple counterparties. Each fill shows who acted (`traderAddress`), the `size` (shares), the `price` (decimal 0–1), the `usdcSize` (USDC value), and whether they were the `MAKER` or `TAKER` (`liquidityRole`).

<Tip>
  You can get a transaction hash from the [Get Trader Activity](/api-reference/endpoints/get-trader-activity) endpoint — every activity item includes a `txHash` you can feed straight into this endpoint.
</Tip>
