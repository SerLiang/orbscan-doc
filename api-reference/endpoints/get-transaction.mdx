Use this endpoint to look **inside a single transaction**. Given a transaction hash, it returns a decoded summary and a breakdown of every on-chain action (fill) that happened within it.

The top-level `sentence` field gives you a ready-to-read description, for example:

> Buy 3604.58 No for 3546.12269 in `Will Bitcoin dip to 59,000 on June 9?`

The `actions` array then lists each individual fill — one transaction often contains several, because a single trade can be matched against multiple counterparties. Each fill shows who acted (`traderAddress`), the `size` (shares), the `price` (decimal 0–1), the `usdcSize` (USDC value), and whether they were the `MAKER` or `TAKER` (`liquidityRole`).

<Tip>
  You can get a transaction hash from the [Get Trader Activity](/api-reference/endpoints/get-trader-activity) endpoint — every activity item includes a `txHash` you can feed straight into this endpoint.
</Tip>

<Note>
  The `txHash` must be a 32-byte hex hash. A malformed value returns HTTP `400` with `"Invalid txHash format"`, while a well-formed hash that isn't indexed returns HTTP `200` with `data: null`. See [Errors](/api-reference/errors).
</Note>

## Regular trades vs combo trades

The top-level `sourceType` tells you which kind of transaction you're looking at:

- **`TRADE`** — a regular order fill. The individual fills are in `actions`, and `comboActions` is `null`.
- **`COMBO`** — a combo (parlay) trade that bundles several market outcomes into a single position. The fills are in `comboActions`, and `actions` is `null`. Because a combo spans more than one market, the top-level `marketId` and `marketSlug` are also `null`, and the `sentence` reads like `Buy Combo position for $4.83699`.

## The `comboActions` array

Each entry in `comboActions` is a single trader's fill of a combo position. Alongside the usual trade fields it carries a `comboPositionId` and a `legs` array describing every market outcome the combo covers.

<Expandable title="comboActions object fields">
  <ResponseField name="actionType" type="string">
    Action label for this fill — `Buy` or `Sell`.
  </ResponseField>

  <ResponseField name="comboPositionId" type="string">
    Identifier of the combo position this fill belongs to.
  </ResponseField>

  <ResponseField name="size" type="string">
    Number of combo shares in this fill.
  </ResponseField>

  <ResponseField name="price" type="string">
    Price per combo share as a decimal (0–1).
  </ResponseField>

  <ResponseField name="usdcSize" type="string">
    USDC value of this fill.
  </ResponseField>

  <ResponseField name="traderAddress" type="string">
    Address that performed this fill.
  </ResponseField>

  <ResponseField name="txHash" type="string">
    On-chain transaction hash.
  </ResponseField>

  <ResponseField name="blockTimestamp" type="integer">
    Block timestamp (Unix seconds).
  </ResponseField>

  <ResponseField name="fee" type="string">
    Fee charged for this fill, in USDC.
  </ResponseField>

  <ResponseField name="legs" type="array">
    The market outcomes that make up the combo. Each leg has `marketId`, `marketTitle`, `marketSlug`, `eventSlug`, `logo`, `outcomeIndex`, `outcome`, and `outcomePrice` (0–1 scale).
  </ResponseField>
</Expandable>
