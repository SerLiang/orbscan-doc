---
title: "Get deposits and withdrawals"
sidebarTitle: "Get deposits and withdrawals"
description: "Return the combined USDC deposit and withdrawal history for a Polymarket wallet, newest first."
openapi: "openapi.json GET /v1/trader/{address}/deposits-withdrawals"
---

Use this endpoint to retrieve indexed USDC deposits and withdrawals for a wallet. It returns one combined, newest-first list where each record's `type` is either `deposit` or `withdrawal`. Transfers from known reward and system addresses are excluded.

Every item includes the `amount` (in USDC, as a string), the `blockTimestamp` (Unix seconds), the on-chain `txHash`, and the counterparty `address`.

<Note>
  For deposits, the counterparty `address` may be the zero address (`0x0000...0000`) when funds are bridged in rather than sent from another wallet.
</Note>

<Tip>
  Like the activity endpoint, this list is paginated. Pass the returned `nextCursor` back as the `cursor` query parameter to load the next page.
</Tip>
