---

The `/v1/markets/{slug}/activity` endpoint returns a paginated feed of recent trades executed on a specific Polymarket prediction market. Each activity record includes the trader's wallet address, the outcome and direction of their trade, the price and USD size, and the on-chain Polygon transaction hash for independent verification. You can filter by minimum trade size or direction to focus on the signals most relevant to your use case.

## Endpoint

```
GET https://api.orbscan.com/v1/markets/{slug}/activity
```

## Path Parameters

<ParamField path="slug" type="string" required>
  The URL-safe unique identifier for the market. Retrieve slugs from the [List Markets](/api-reference/markets/list-markets) endpoint.
</ParamField>

## Query Parameters

<ParamField query="limit" type="integer" default="20">
  Number of activity records to return per page. Maximum value is `100`.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip before returning the page. Use with `limit` to paginate through results.
</ParamField>

<ParamField query="min_size" type="number">
  Filter results to only include trades with a USD value greater than or equal to this amount. Useful for surfacing whale activity.
</ParamField>

<ParamField query="side" type="string" default="all">
  Filter results by trade direction. Accepted values: `BUY`, `SELL`, `all`.
</ParamField>

## Request Example

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.orbscan.com/v1/markets/will-bitcoin-hit-100k/activity?limit=20&side=BUY&min_size=500" \
  --header "Authorization: Bearer $ORBSCAN_API_KEY"
```

```python Python
import requests

url = "https://api.orbscan.com/v1/markets/will-bitcoin-hit-100k/activity"
headers = {"Authorization": "Bearer $ORBSCAN_API_KEY"}
params = {
    "limit": 20,
    "side": "BUY",
    "min_size": 500,
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

</CodeGroup>

## Response Fields

<ResponseField name="total" type="integer">
  Total number of activity records matching your query filters.
</ResponseField>

<ResponseField name="limit" type="integer">
  Number of records returned in this response.
</ResponseField>

<ResponseField name="offset" type="integer">
  Offset applied to this response.
</ResponseField>

<ResponseField name="activity" type="array">
  Array of trade objects.

  <Expandable title="Activity object fields">
    <ResponseField name="trader_address" type="string">
      The Polygon wallet address of the trader who executed the trade.
    </ResponseField>

    <ResponseField name="trader_username" type="string | null">
      The trader's display name on Polymarket, if they have set one. Returns `null` if no username is set.
    </ResponseField>

    <ResponseField name="outcome" type="string">
      The market outcome that was traded (e.g. `"Yes"`, `"No"`, or a team name).
    </ResponseField>

    <ResponseField name="side" type="string">
      Direction of the trade. Either `BUY` or `SELL`.
    </ResponseField>

    <ResponseField name="price" type="number">
      Price per share at the time of the trade, expressed as a decimal between `0` and `1`.
    </ResponseField>

    <ResponseField name="size_usd" type="number">
      Total USD value of the trade.
    </ResponseField>

    <ResponseField name="tx_hash" type="string">
      On-chain Polygon transaction hash. Verify the trade independently on Polygonscan using this value.
    </ResponseField>

    <ResponseField name="timestamp" type="string">
      ISO 8601 datetime at which the trade was executed on-chain.
    </ResponseField>
  </Expandable>
</ResponseField>
