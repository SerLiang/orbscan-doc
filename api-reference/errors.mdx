When a request fails, Orbscan returns the same envelope used for successful responses, with `success` set to `false`, `data` set to `null`, and `code` holding the HTTP status as a string.

```json
{
  "success": false,
  "code": "401",
  "message": "Missing or invalid API key",
  "data": null
}
```

Handle errors by checking `success` first, then branch on `code` (or the HTTP status, which matches).

## Status Codes

| HTTP | `code` | `message` (example) | Cause & fix |
|---|---|---|---|
| `401` | `"401"` | `Missing or invalid API key` | The `apikey` query parameter is missing or wrong. Check the key you're sending. |
| `400` | `"400"` | `Invalid address format` | A path or query value is malformed — most often an `address` that isn't a valid `0x…` hex address. |
| `404` | `"404"` | `Not found: <path>` | The route doesn't exist. Check the endpoint path and spelling. |
| `5xx` | `"5xx"` | — | A transient server or gateway error. Retry with backoff. |

## Empty Results Are Not Errors

A valid request that simply has no data to return still succeeds with HTTP `200` and `success: true`:

<CodeGroup>

```json List endpoint — no matching records
{
  "success": true,
  "code": "0",
  "message": "success",
  "data": { "items": [], "nextCursor": null }
}
```

```json Single lookup — nothing found
{
  "success": true,
  "code": "0",
  "message": "success",
  "data": null
}
```

</CodeGroup>

<Warning>
  Don't treat a `200` with empty `data` as a failure. Always inspect `data` — an empty `items` array (list endpoints) or a `null` `data` (single-record lookups) means "no results," not "error."
</Warning>

## Handling Errors in Code

<CodeGroup>

```python Python
import requests

resp = requests.get(url, timeout=30)
body = resp.json()

if not body["success"]:
    code = body["code"]
    if code == "401":
        raise RuntimeError("Check your Orbscan API key")
    raise RuntimeError(f"Orbscan error {code}: {body['message']}")

data = body["data"]
if not data or (isinstance(data, dict) and not data.get("items")):
    print("No results")
else:
    print(data)
```

```javascript JavaScript
const resp = await fetch(url);
const body = await resp.json();

if (!body.success) {
  if (body.code === "401") throw new Error("Check your Orbscan API key");
  throw new Error(`Orbscan error ${body.code}: ${body.message}`);
}

const { data } = body;
if (!data || (Array.isArray(data.items) && data.items.length === 0)) {
  console.log("No results");
} else {
  console.log(data);
}
```

</CodeGroup>
