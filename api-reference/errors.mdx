Every response — success or failure — uses the same envelope with three fields: `message`, `status_code`, and `data`.

- On **success**: `status_code` is `"1"`, `message` is `"OK"`, and `data` holds the result.
- On **error**: `status_code` is `"0"`, `message` describes the problem, and `data` is `null`.

Use the **HTTP status code** to determine the type of error.

```json
{
  "message": "Missing or invalid API key",
  "status_code": "0",
  "data": null
}
```

## Status Codes

| HTTP | `message` (example) | Cause & fix |
|---|---|---|
| `401` | `Missing or invalid API key` | The `Authorization: Bearer` header is missing or the key is wrong. Check the key you're sending. |
| `400` | `Invalid address format` / `Invalid txHash format` | A path or query value is malformed — for example an `address` that isn't a valid `0x…` hex address, or a `txHash` that isn't a 32-byte hex hash. |
| `404` | `Not found` | The API endpoint does not exist. Check the path and spelling. A well-formed request for a resource that simply isn't indexed returns `200`, not `404` — see below. |
| `429` | — | Rate limit exceeded. Wait for the window to reset, then retry with exponential backoff. See [Rate Limits](/api-reference/rate-limits). |
| `5xx` | — | A transient server or gateway error. Retry with backoff. |

## Empty Results Are Not Errors

A valid request that finds nothing is not an error: it still succeeds with HTTP `200` and `status_code` `"1"`. The shape of `data` depends on the endpoint:

- **List endpoints** (activity, deposits & withdrawals, positions, rewards) return an empty `items` array:

```json
{
  "message": "OK",
  "status_code": "1",
  "data": { "items": [], "nextCursor": null }
}
```

- **Single-object endpoints** (for example [Get Actions by Hash](/api-reference/endpoints/get-transaction)) return `data: null`:

```json
{
  "message": "OK",
  "status_code": "1",
  "data": null
}
```

<Warning>
  Don't treat a `200` with empty `data` as a failure. An empty `items` array or a `null` `data` means "no results," not "error."
</Warning>

## Handling Errors in Code

<CodeGroup>

```python Python
import requests

resp = requests.get(url, timeout=30)
body = resp.json()

if body["status_code"] != "1":
    raise RuntimeError(f"Orbscan error {resp.status_code}: {body['message']}")

data = body["data"]
empty_list = isinstance(data, dict) and data.get("items") == []
if data is None or empty_list:
    print("No results")
else:
    print(data)
```

```javascript JavaScript
const resp = await fetch(url);
const body = await resp.json();

if (body.status_code !== "1") {
  throw new Error(`Orbscan error ${resp.status}: ${body.message}`);
}

const { data } = body;
if (!data || (Array.isArray(data.items) && data.items.length === 0)) {
  console.log("No results");
} else {
  console.log(data);
}
```

</CodeGroup>
