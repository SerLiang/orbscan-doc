title: "GET /v1/traders/{address}/trades — Trade History"

---

The trades endpoint returns the complete on-chain trade history for a Polymarket wallet, ordered from newest to oldest. Each record includes the market traded, the side and size of the transaction, the price at execution, and the Polygon transaction hash you can use for independent on-chain verification.

`GET https://api.orbscan.com/v1/traders/{address}/trades`

## Path Parameters

<ParamField path="address" type="string" required>
  The 0x-prefixed, 42-character Ethereum wallet address whose trade history you want to retrieve. Case-insensitive.
</ParamField>

## Query Parameters

<ParamField query="limit" type="integer">
  Number of trade records to return per page. Accepts values between `1` and `500`. Defaults to `50`.
</ParamField>

<ParamField query="offset" type="integer">
  Zero-based index of the first trade to return. Use with `limit` to paginate through large histories. Defaults to `0`.
</ParamField>

<ParamField query="market_slug" type="string">
  Filter results to trades in a single market. Pass the URL-safe market slug (e.g. `will-btc-hit-100k-by-eoy-2025`) to narrow the response to that market's activity only.
</ParamField>

<ParamField query="side" type="string">
  Filter by trade direction. Accepted values are `BUY` and `SELL`. Omit to return trades on both sides.
</ParamField>

<ParamField query="start_date" type="string">
  Beginning of the date range filter in ISO 8601 format (e.g. `2024-01-01`). Returns trades on or after this date. Must be used with `end_date` for a bounded window.
</ParamField>

<ParamField query="end_date" type="string">
  End of the date range filter in ISO 8601 format (e.g. `2024-03-31`). Returns trades on or before this date. Must be used with `start_date` for a bounded window.
</ParamField>

## Request Example

<CodeGroup>

```bash curl
curl --request GET \
  --url 'https://api.orbscan.com/v1/traders/0x204f72f35326db932158cba6adff0b9a1da95e14/trades?limit=50&side=BUY&start_date=2024-01-01&end_date=2024-03-31' \
  --header 'Authorization: Bearer $ORBSCAN_API_KEY'
```

```python Python
import requests

address = "0x204f72f35326db932158cba6adff0b9a1da95e14"

params = {
    "limit": 50,
    "side": "BUY",
    "start_date": "2024-01-01",
    "end_date": "2024-03-31",
}

response = requests.get(
    f"https://api.orbscan.com/v1/traders/{address}/trades",
    headers={"Authorization": "Bearer $ORBSCAN_API_KEY"},
    params=params,
)

print(response.json())
```

</CodeGroup>

## Response Fields

The response is an array of trade objects. Each object contains the following fields:

<ResponseField name="trade_id" type="string">
  A unique identifier for this trade record within the Orbscan system.
</ResponseField>

<ResponseField name="market_slug" type="string">
  URL-safe identifier for the market in which the trade was executed.
</ResponseField>

<ResponseField name="market_question" type="string">
  The full question text of the prediction market at the time of the trade.
</ResponseField>

<ResponseField name="outcome" type="string">
  The outcome shares that were bought or sold in this trade (e.g. `"Yes"` or `"No"`).
</ResponseField>

<ResponseField name="side" type="string">
  Direction of the trade. Either `"BUY"` (shares purchased) or `"SELL"` (shares sold).
</ResponseField>

<ResponseField name="shares" type="number">
  The number of outcome shares transacted in this trade.
</ResponseField>

<ResponseField name="price" type="number">
  The per-share price at which the trade was executed, expressed as a decimal between `0` and `1`.
</ResponseField>

<ResponseField name="size_usd" type="number">
  The total USD value of the trade, calculated as `shares × price`. For sells, this represents the proceeds received.
</ResponseField>

<ResponseField name="tx_hash" type="string">
  The Polygon blockchain transaction hash for this trade. Use this to look up the raw transaction on Polygonscan or any Polygon-compatible explorer.
</ResponseField>

<ResponseField name="timestamp" type="string">
  The date and time the trade was confirmed on-chain, in ISO 8601 format (e.g. `"2024-02-14T09:23:11Z"`).
</ResponseField>
