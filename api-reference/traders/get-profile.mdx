The profile endpoint returns a comprehensive analytics snapshot for a single Polymarket trader identified by their Ethereum wallet address. Use it to surface leaderboard stats, power copy-trading features, or build trader profile pages — all resolved from on-chain and Polymarket activity data.

`GET https://api.orbscan.com/v1/trader/{address}/profile`

## Path Parameters

<ParamField path="address" type="string" required>
  The Ethereum wallet address of the trader to look up. Must be 0x-prefixed and exactly 42 characters long. The lookup is case-insensitive, but the response always returns the checksummed form.
</ParamField>

## Request Example

<CodeGroup>

```bash curl
curl --request GET \
  --url https://api.orbscan.com/v1/trader/0x6a72f61820b26b1fe4d956e17b6dc2a1ea3033ee/profile \
  --header 'Authorization: Bearer $ORBSCAN_API_KEY'
```

```python Python
import requests

address = "0x6a72f61820b26b1fe4d956e17b6dc2a1ea3033ee"

response = requests.get(
    f"https://api.orbscan.com/v1/trader/{address}/profile",
    headers={"Authorization": "Bearer $ORBSCAN_API_KEY"},
)

print(response.json())
```

```javascript JavaScript
const address = "0x6a72f61820b26b1fe4d956e17b6dc2a1ea3033ee";

const response = await fetch(
  `https://api.orbscan.com/v1/trader/${address}/profile`,
  {
    headers: {
      Authorization: `Bearer ${process.env.ORBSCAN_API_KEY}`,
    },
  }
);

const data = await response.json();
console.log(data);
```

## Response Fields

<ResponseField name="address" type="string">
  The checksummed Ethereum wallet address of the trader, normalised to EIP-55 format regardless of how the address was supplied in the request.
</ResponseField>

<ResponseField name="username" type="string | null">
  The display name the trader has set on Polymarket, or `null` if no username has been configured.
</ResponseField>

<ResponseField name="pnl_30d" type="number">
  Combined realized and unrealized profit and loss over the trailing 30-day window, denominated in USD. Negative values indicate a net loss.
</ResponseField>

<ResponseField name="pnl_total" type="number">
  Lifetime total PnL in USD, spanning all activity since the wallet's first Polymarket trade.
</ResponseField>

<ResponseField name="pnl_change_pct" type="number">
  Percentage change in PnL compared to the previous 30-day period. A value of `12.5` means PnL improved by 12.5% relative to the period before.
</ResponseField>

<ResponseField name="win_rate" type="number">
  The fraction of resolved markets in which the trader held shares in the winning outcome, expressed as a decimal between `0` and `1`. A value of `0.6` represents a 60% win rate.
</ResponseField>

<ResponseField name="sharpe_ratio" type="number">
  Risk-adjusted return score calculated from the trader's daily PnL series. Higher values indicate better return per unit of volatility. Values above `1.0` are generally considered favorable.
</ResponseField>

<ResponseField name="position_value" type="number">
  Current mark-to-market value of all open positions held by the trader, in USD.
</ResponseField>

<ResponseField name="active_markets" type="integer">
  The number of prediction markets in which the trader currently holds at least one open position.
</ResponseField>

<ResponseField name="resolved_count" type="integer">
  Total number of markets the trader has participated in that have since resolved.
</ResponseField>

<ResponseField name="copy_pnl_7d" type="number">
  Hypothetical PnL (USD) that would have been earned over the last 7 days by mirroring this trader's entries and exits at the same prices. Useful for evaluating copy-trading potential.
</ResponseField>

## Error Cases

| Status | Code | Description |
|--------|------|-------------|
| `400 Bad Request` | `INVALID_ADDRESS` | The `address` path parameter is not a valid 0x-prefixed 42-character Ethereum address. |
| `404 Not Found` | `TRADER_NOT_FOUND` | The address is well-formed but has no recorded Polymarket activity. |
