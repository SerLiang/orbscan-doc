Authenticate to the Orbscan Open API with your **API key**, passed as a Bearer token in the Authorization header. Requests without a valid key are rejected with a `401 `response.

## Getting an API Key

Request an API key by filling out the [sign-up form](https://orbscan.com/contactus). Once approved, your key provides access to all available endpoints.

<Warning>
  Your API key is a secret. Keep it server-side, never commit it to a public repository, and never expose it in client-side code. If a key is leaked, rotate it.
</Warning>

## Using Your API Key

Pass your key as a **Bearer token** in the `Authorization` header on every request:

```http
Authorization: Bearer YOUR_API_KEY
```

### Example request

```bash cURL
curl "https://api.orbscan.com/v1/trader/0x6a72f61820b26b1fe4d956e17b6dc2a1ea3033ee/activity?limit=50" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

resp = requests.get(
    "https://api.orbscan.com/v1/trader/0x6a72f61820b26b1fe4d956e17b6dc2a1ea3033ee/activity",
    params={"limit": 50},
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    timeout=30,
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch(
  "https://api.orbscan.com/v1/trader/0x6a72f61820b26b1fe4d956e17b6dc2a1ea3033ee/activity?limit=50",
  { headers: { Authorization: "Bearer YOUR_API_KEY" } }
);
const body = await resp.json();
console.log(body);
```

## Verifying Authentication

A successful, authenticated request returns `success: true`:

```json
{
  "success": true,
  "code": "0",
  "message": "success",
  "data": { }
}
```

A missing or invalid key returns `401`:

```json
{
  "success": false,
  "code": "401",
  "message": "Missing or invalid API key",
  "data": null
}
```
