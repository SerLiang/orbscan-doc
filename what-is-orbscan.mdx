title: "What is Orbscan?"
description: "An on-chain activity explorer for Polymarket prediction markets."
---

[Orbscan](https://orbscan.com) is an on-chain activity explorer for [Polymarket](https://polymarket.com) prediction markets. It reads events directly from the chain and exposes them through a small JSON API, so you can:

- Look up a trader's **current portfolio** of open positions and USD holdings.
- Pull a trader's **full activity history** — every buy, sell, and redeem across every market they have touched, paginated.
- Decode any **transaction hash** into a human-readable summary and the individual actions it contains.

<Note>
  There is no indexer to run and no on-chain data to parse yourself — Orbscan has already done that work.
</Note>

## Response format

All endpoints are served under `https://orbscan.com/api/v1` and return a common envelope:

```json
{ "success": true, "code": "0", "message": "success", "data": {} }
```

`success`, `code`, and `message` are consistent across every response, so you can handle errors the same way regardless of which endpoint you call. The endpoint-specific payload always lives under `data`.
