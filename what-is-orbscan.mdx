[Orbscan](https://orbscan.com) is an on-chain activity explorer for [Polymarket](https://polymarket.com) prediction markets. It reads events directly from the chain and exposes them through a small JSON API, so you can:

- Pull a trader's **full activity history** across markets.
- List a trader's **deposits and withdrawals** with amounts and transaction hashes.
- Decode any **transaction hash** into a human-readable summary and its individual actions.

<Note>
  There is no indexer to run and no on-chain data to parse yourself — Orbscan has already done that work.
</Note>

## Response format

All endpoints are served under `https://orbscan.com/open-api/v1` and return a common envelope:

```json
{
  "success": true,
  "code": "0",
  "message": "success",
  "data": {}
}
```

`success`, `code`, and `message` are consistent across successful responses. The endpoint-specific payload lives under `data`.
