This guide gets you from zero to a live API response in under five minutes. You'll obtain an API key, call the trader profile endpoint with a real wallet address, and inspect the JSON response — giving you a working template you can adapt for any other Orbscan endpoint.

<Steps>
  <Step title="Get your API key">
    Every request to the Orbscan API requires a valid API key in the `Authorization` header. If you don't have one yet, follow the steps in the [Authentication](/authentication) guide to create an account and generate a key.

    Once you have your key, store it in an environment variable so you can reference it easily:

    ```bash
    export ORBSCAN_API_KEY="your_api_key_here"
    ```
  </Step>
  <Step title="Fetch trader activity">
    The trader activity endpoint returns paginated buy, sell, and redeem history for any Polymarket wallet address. Make the following request, replacing the example address with any wallet you want to inspect.

    <CodeGroup>

    ```bash curl
    curl -X GET "https://api.orbscan.com/v1/trader/0x6a72f61820b26b1fe4d956e17b6dc2a1ea3033ee/activity?limit=5" \
      -H "Authorization: Bearer $ORBSCAN_API_KEY" \
      -H "Accept: application/json"
    ```

    ```python Python
    import os
    import requests
    
    api_key = os.environ["ORBSCAN_API_KEY"]
    address = "0x6a72f61820b26b1fe4d956e17b6dc2a1ea3033ee"
    
    response = requests.get(
        f"https://api.orbscan.com/v1/trader/{address}/activity",
        headers={
            "Authorization": f"Bearer {api_key}",
            "Accept": "application/json",
        },
        params={"limit": 5},
    )
    
    data = response.json()
    print(data)
    ```

    </CodeGroup>

    <Tip>
      You can use any valid Polymarket wallet address. Browse the top traders on [orbscan.com](https://orbscan.com) to find interesting wallets to explore.
    </Tip>
  </Step>
  <Step title="Inspect the response">
    A successful request returns a JSON object with a paginated list of trades. Here's an example response:

    ```json
    {
      "message": "OK",
      "status_code": "1",
      "data": {
        "items": [
          {
            "blockTimestamp": 1782861128,
            "actionType": "Redeem",
            "price": "1",
            "size": "5",
            "fee": "0",
            "usdcSize": "5",
            "netSharesTransferred": "-5",
            "txHash": "0x71bf46c3089e2349a62ec6b93638522e8cc635a9836f1308ac7621ce1ecbb609",
            "marketTitle": "Will France win on 2026-06-30?",
            "positionSide": "Yes",
            "traderAddress": "0x6a72f61820b26b1fe4d956e17b6dc2a1ea3033ee",
            "liquidityRole": null
          }
        ],
        "nextCursor": "MTc4Mjg2MTEyOH..."
      }
    }
    ```

    Key fields to note:

    | Field | Description |
    | --- | --- |
    | `blockTimestamp` | Unix timestamp (seconds) of the trade. |
    | `actionType` | Action label: `Buy`, `Sell`, or `Redeem`. |
    | `price` | Price per share as a decimal (0–1). `"0.78"` means 78¢ per share. |
    | `size` | Number of shares. |
    | `usdcSize` | Gross USDC value of the trade. |
    | `netSharesTransferred` | Shares received (positive) or sent (negative). |
    | `nextCursor` | Pass this back as `cursor` to fetch the next page. `null` when no more results. |
  </Step>
