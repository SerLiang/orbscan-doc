This guide gets you from zero to a live API response in under five minutes. You'll obtain an API key, call the trader profile endpoint with a real wallet address, and inspect the JSON response — giving you a working template you can adapt for any other Orbscan endpoint.

<Steps>
  <Step title="Get your API key">
    Every request to the Orbscan API requires a valid API key in the `Authorization` header. If you don't have one yet, follow the steps in the [Authentication](/authentication) guide to create an account and generate a key.

    Once you have your key, store it in an environment variable so you can reference it easily:

    ```bash
    export ORBSCAN_API_KEY="your_api_key_here"
    ```
  </Step>

  <Step title="Fetch a trader profile">
    The trader profile endpoint returns performance metrics and account details for any Polymarket wallet address. Make the following request, replacing the example address with any wallet you want to inspect.

    <CodeGroup>
      ```bash curl
      curl -X GET "https://api.orbscan.com/v1/traders/0x204f72f35326db932158cba6adff0b9a1da95e14/profile" \
        -H "Authorization: Bearer $ORBSCAN_API_KEY" \
        -H "Accept: application/json"
      ```

      ```python Python
      import os
      import requests

      api_key = os.environ["ORBSCAN_API_KEY"]
      address = "0x204f72f35326db932158cba6adff0b9a1da95e14"

      response = requests.get(
          f"https://api.orbscan.com/v1/traders/{address}/profile",
          headers={
              "Authorization": f"Bearer {api_key}",
              "Accept": "application/json",
          },
      )

      profile = response.json()
      print(profile)
      ```
    </CodeGroup>

    <Tip>
      You can use any valid Polymarket wallet address. To find interesting wallets to explore, check the [leaderboard endpoint](/api-reference/leaderboard/get-leaderboard) or browse the top traders on [orbscan.com](https://orbscan.com).
    </Tip>
  </Step>

  <Step title="Inspect the response">
    A successful request returns a JSON object with the trader's account details and computed performance metrics. Here's an example response for the wallet used above:

    ```json
    {
      "address": "0x204f72f35326db932158cba6adff0b9a1da95e14",
      "username": "sharpbetter",
      "pnl_30d": 18420.55,
      "positions_count": 12,
      "win_rate": 0.67,
      "sharpe_ratio": 2.14,
      "active_markets": [
        {
          "market_id": "0xabc123",
          "title": "Will the Fed cut rates in September 2025?",
          "side": "YES",
          "current_value_usd": 3200.00,
          "unrealized_pnl": 540.00
        },
        {
          "market_id": "0xdef456",
          "title": "Will Bitcoin exceed $120k before July 2025?",
          "side": "NO",
          "current_value_usd": 1750.00,
          "unrealized_pnl": -210.00
        }
      ]
    }
    ```

    Key fields to note:

    | Field | Description |
    |---|---|
    | `address` | The on-chain wallet address queried. |
    | `username` | Display name associated with the wallet, if set. |
    | `pnl_30d` | Realized + unrealized profit and loss over the last 30 days, in USD. |
    | `positions_count` | Number of open positions currently held by this wallet. |
    | `win_rate` | Fraction of resolved trades where the trader selected the correct outcome. |
    | `sharpe_ratio` | Risk-adjusted return metric computed over the trailing 30 days. |
    | `active_markets` | List of markets the wallet currently holds positions in, with mark-to-market values. |
  </Step>
