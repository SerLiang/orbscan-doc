This guide gets you from zero to a live API response in under five minutes. You'll obtain an API key, call the trader activity endpoint with a real wallet address, and inspect the JSON response. You can adapt the same request pattern for any other Orbscan endpoint.

<Steps>
  <Step title="Get your API key">
    Every request to the Orbscan API requires a valid API key. If you don't have one, use the [Orbscan contact form](https://orbscan.com/contactus) to request access. See [Authentication](/api-reference/authentication) for details.

    Once you have your key, store it in an environment variable so you can reference it easily:

    ```bash
    export ORBSCAN_API_KEY="your_api_key_here"
    ```
  </Step>
  <Step title="Fetch trader activity">
    The trader activity endpoint returns paginated buy, sell, and redeem history for any Polymarket wallet address. Make the following request, replacing the example address with any wallet you want to inspect.

    <CodeGroup>

    ```bash curl
    curl -X GET "https://api.orbscan.com/v1/trader/0x6a72f61820b26b1fe4d956e17b6dc2a1ea3033ee/activity?limit=1&toTimestamp=1782861128" \
      -H "Authorization: Bearer $ORBSCAN_API_KEY" \
      -H "Accept: application/json"
    ```

    ```python Python
    import os
    import requests
    
    api_key = os.environ["ORBSCAN_API_KEY"]
    address = "0x6a72f61820b26b1fe4d956e17b6dc2a1ea3033ee"
    
    response = requests.get(
        f"https://api.orbscan.com/v1/trader/{address}/activity",
        headers={
            "Authorization": f"Bearer {api_key}",
            "Accept": "application/json",
        },
        params={"limit": 1, "toTimestamp": 1782861128},
    )
    
    data = response.json()
    print(data)
    ```

    </CodeGroup>

    <Tip>
      You can use any valid Polymarket wallet address. Browse the top traders on [orbscan.com](https://orbscan.com) to find interesting wallets to explore.
    </Tip>
  </Step>

    Key fields to note:

    | Field | Description |
    | --- | --- |
    | `blockTimestamp` | Unix timestamp, in seconds, of the action. |
    | `actionType` | Action label: `Buy`, `Sell`, or `Redeem`. |
    | `price` | Price per share as a decimal from 0 to 1. `"0.78"` means 78 cents per share. |
    | `size` | Number of shares. |
    | `usdcSize` | Gross USDC value of the action. |
    | `netSharesTransferred` | Shares received (positive) or sent (negative). |
    | `nextCursor` | Pass this back as `cursor` to fetch the next page. `null` when no more results. |
