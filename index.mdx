---
title: "Authentication"
description: "Authenticate requests to the Orbscan Open API."
---

Every request to the Orbscan Open API requires an API key in the `apikey` query parameter.

```bash
curl "https://orbscan.com/open-api/v1/trader/0xYOUR_ADDRESS/activity?apikey=$ORBSCAN_API_KEY"
```

<Warning>
  Keep your API key private. Do not commit it to source control, expose it in client-side code, or include a live key in screenshots and public URLs.
</Warning>

Store the key in an environment variable named `ORBSCAN_API_KEY` and inject it only when making a server-side request.
