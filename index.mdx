Orbscan combines indexed on-chain activity with persisted L2 order book data for [Polymarket](https://polymarket.com/) prediction markets. You can pull wallet activity, positions, transfers, indexed transaction details, and crypto-market order book history through a JSON API without running your own indexer.

## Get up and running in three steps

New to Orbscan? Follow this path to go from zero to your first live data response.

<Steps>
  <Step title="Get your API key">
    Request a key from [Orbscan](https://orbscan.com/contactus). It authenticates every request you make. See [Authentication](/api-reference/authentication) for full details.
  </Step>
  <Step title="Make your first request">
    Pass your key in the `Authorization: Bearer` header and call an endpoint. For example, request a trader's activity:

    ```bash
    curl "https://api.orbscan.com/v1/trader/{address}/activity?limit=50" \
      -H "Authorization: Bearer <your_api_key>"
    ```
  </Step>
  <Step title="Explore the endpoints">
    The reference covers [wallet address](/api-reference/endpoints/get-wallet-address) and [portfolio](/api-reference/endpoints/get-portfolio) lookups, [open](/api-reference/endpoints/get-open-positions) and [closed positions](/api-reference/endpoints/get-closed-positions), [combo positions](/api-reference/endpoints/get-combo-open-positions), [activity](/api-reference/endpoints/get-trader-activity), [rewards](/api-reference/endpoints/get-rewards), [deposits and withdrawals](/api-reference/endpoints/get-deposits-withdrawals), and [actions by transaction hash](/api-reference/endpoints/get-transaction). It also covers the [Order Book API](/api-reference/market/orderbook-markets). Each endpoint page has an interactive **Try it** playground.
  </Step>
</Steps>
